# 🛠️ El Taller de Walter

> Landing page para un servicio técnico de computadoras, armado de PC y venta de hardware.

![El Taller de Walter](assets/img/logo.png)

## 📌 Sobre el proyecto

**El Taller de Walter** es una landing page desarrollada para representar la identidad de un taller de reparación y venta de hardware.

El proyecto busca combinar una estética tecnológica con una identidad visual propia, utilizando una mascota como elemento principal de la marca y distintas ilustraciones personalizadas para representar los servicios ofrecidos.

La página fue diseñada pensando tanto en la presentación visual como en la experiencia del usuario y la adaptación a distintos dispositivos.

---

## 🚀 Características

- Diseño responsive para desktop, tablet y dispositivos móviles.
- Hero principal con identidad visual personalizada.
- Sección de servicios con imágenes propias.
- Sección de productos destacados.
- Testimonios de clientes.
- Sección informativa sobre el taller.
- Navegación con efectos hover.
- Animaciones y transiciones.
- Diseño basado en una paleta de colores personalizada.
- Arquitectura SCSS modular.

---

## 🧰 Tecnologías utilizadas

- HTML5
- SCSS

- GitHub

---

## 🎨 Identidad visual

Uno de los objetivos principales del proyecto fue crear una identidad visual reconocible y alejarse de una landing genérica.

La mascota de **El Taller de Walter** funciona como elemento central de la marca y aparece representando distintas situaciones relacionadas con los servicios del negocio.

Las ilustraciones fueron diseñadas específicamente para mantener una estética coherente entre las diferentes secciones.
